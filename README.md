# NFC Digital Business Card

**NFC Smart Solutions | MVP 01**

Version: **v0.2 — Demo**  
Status: Functional prototype  
Date: 18 October 2026

## Project Overview

A responsive digital business card designed to be accessed through an NFC card or a QR code.

The project demonstrates how physical NFC technology can connect users to a digital profile that can be updated without rewriting the NFC tag.

## Features — v0.2

- Responsive layout for desktop and mobile devices
- Email and telephone demo buttons
- Disabled WhatsApp and LinkedIn demo buttons
- Downloadable vCard (.vcf)
- Native sharing functionality with browser fallback
- Static QR code linked to the public website
- Hosting through GitHub Pages

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages
- NFC NTAG215 cards (planned physical testing)

No backend, database, paid hosting or external framework is required for this prototype.

## Testing

- Responsive layout tested on Android
- Email and telephone links tested on Android
- vCard download and import tested
- Canonical URL verified in macOS Contacts
- QR code scanned successfully on Android
- QR code displayed correctly on mobile and desktop

## Known Limitations

- Contact details are placeholders
- WhatsApp and LinkedIn are intentionally disabled
- NFC card programming has not yet been verified
- No customer dashboard or analytics
